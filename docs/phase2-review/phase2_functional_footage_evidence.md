| 项 | 内容 |
|---|---|
| 原片改动 | **无**。所有片段均用 `-ss / -t / -c copy` 从原片 stream copy 提取到 `D:\tmp\`，未覆盖、未重编码原始素材 |
| 连续片段 | cloud_A 五个区间各提取 1 条连续原片片段（共 5 条，合计 340s），见 §2 |
| 密集采样 | cloud_A 五区间 **每 2s** 一帧（屏幕裁剪放大，5×4 网格，带绝对原片时间码）；cloud_F 全片 **每 10s / 每 5s / 每 2s**，开头手持段 **每 1s**，语音交互段 **每 1s** |
| 时间码 | `drawtext=text='%{pts\:hms}'` + `-copyts`，输出为**绝对原片时间码**（例：R4 首帧 = `00:04:36.000`，对应 `-ss 275` 后的首个采样点） |
| 采样精度 | **±1s**（2s 间隔）/ **±0.5s**（1s 间隔）。时间码是采样点，不是语句的精确起始秒；不得当作逐帧审看结论 |
| 屏幕裁剪 | cloud_A `crop=700:680:190:320`；cloud_F `crop=760:1100:150:400` |
| 旋转处理 | cloud_F 含 `displaymatrix rotation=-90`。ffmpeg 默认自动旋转后屏幕文字侧向不可读；本轮统一用 **`-noautorotate`** 读取编码帧（1080×1920），屏幕文字水平正立。`showinfo` 的 `s:1920x1080` 是自动旋转后的显示帧，与本轮取证帧不同，不得混用 |
| 技术基线 | 已做全片解码、blackdetect（≥0.5s）、volumedetect、silencedetect；**未做**语义听审、未做逐帧人工审看、未调用任何云端转录/生图/视频生成 |
| 证据等级口径 | **屏幕文字只能证明「该文字/UI 在该时刻出现在真实设备屏幕上」**，不能直接等同：后台数据写入成功、语音识别准确、数据库一致性、闹钟到点触发、设备主动开口播报 |

**L1–L4 统一定义（本轮起适用于全部 Phase 2 文件）**

| 等级 | 定义 | 严禁外推 |
|---|---|---|
| **L1** | 真实功能操作画面，有实际操作证据（连续可见的用户操作 / 设备界面交互 / 屏幕文字） | 不得外推为后台写入成功、识别准确或端到端功能成功 |
