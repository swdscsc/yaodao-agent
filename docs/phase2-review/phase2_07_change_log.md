## 1. 三处旁白逐字前后对照（修改前 / 修改后 / 修改原因）

### SH02（0:08–0:16，S1）
- **修改前**：很多慢病老人，每天要和一堆药打交道。
- **修改后**：爸妈每天要记的事情不少，用药安排也容易让人操心。
- **原因**：原「很多慢病老人，每天要和一堆药打交道」沿用旧稿无来源的群体统计（类似此前「数千万慢病老人」问题）。改为从爸妈个人视角表述「日常安排多、用药容易操心」，去掉无来源泛化，不暗示功能已可用。

### SH03（0:16–0:25，S1）
- **修改前**：有没有一种可能——不用智能手机，只要开口说话，就能替我们盯住吃药这件事？
- **修改后**：有没有一种可能，让用药安排和提醒，可以通过一句话来完成？
- **原因**：原「不用智能手机」为绝对化表述（PHASE2-04/05 已列为待修），且「替我们盯住吃药这件事」隐含设备已能完成。改为「让用药安排和提醒，可以通过一句话来完成」，去掉绝对化与不实暗示。

### SH14（2:12–2:25，S3 功能3 分组查询）
- **修改前**：问它「我早上该吃哪些药」，它按餐次把今天的药一条条报给你。
- **修改后**：问它早上该吃哪些药，屏幕会给出按餐次查询的回应；但查询结果是否准确，还需要核对。
- **原因**：原「它按餐次把今天的药一条条报给你」把屏幕查询回应描述成准确的用药清单。改为「屏幕会给出按餐次查询的回应；但查询结果是否准确，还需要核对」，落实任务要求（不把查询回应描述为准确清单、不把提醒描述为服药确认）。
