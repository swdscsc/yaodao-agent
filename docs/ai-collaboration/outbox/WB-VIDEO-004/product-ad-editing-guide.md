# 《AI 产品广告剪辑规范》v1 · 药到 AI 用药管家

| 项 | 值 |
|---|---|
| 定位 | 广告"好看"的判据，供创意导演 / 分镜导演 / 自动剪辑师 / 质量总监共同使用 |
| 关联 | `ad-director-workflow.md`（角色）、`subtitle-signoff-fix.md`（字幕质检）、`recommended-architecture.md`（质检落地） |
| 运行状态 | **规范文档，本轮未制作任何正式宣传片** |
| 合规基线 | 不出现医疗诊断、药品疗效、治愈率、真实用户评价、使用数据；模拟界面必须标注 |

---

## 1. 开场（前 3 秒）

| 规则 | 判据 | 检查方式 |
|---|---|---|
| 前 3 秒必须明确吸引注意力 | 3 s 内出现「问题 / 具体场景 / 视觉悬念」之一 | 抽取 0/1/2/3 s 关键帧 + 人工判读 |
| 不要长时间展示 Logo | Logo 独占画面 ≤0.8 s，且不得作为第一帧 | 帧检测 + EDL |
| 不要用无意义空镜拖时间 | 每个开场镜头必须有 `purpose`，禁止 `atmosphere_only` | shotlist 校验 |
| 快速建立问题/场景/悬念 | 首句旁白或首屏字幕必须点出具体用药困扰 | 文本规则 + 人工 |

**三种可选钩子（不得连续两支广告复用同一种）**：

1. **具体困扰**：老人面对一排药盒、手停在半空（情景演绎，不冒充真实用户）。
2. **视觉悬念**：药盒与手机界面同框，镜头推近一行提示文字（真实 UI 或标注模拟）。
3. **时间压力**：闹钟 / 饭点 / 分药盒的时间线切片，前 2 s 建立"什么时候吃"的问题。

**禁止**：抽象科技粒子开场、地球/脑神经/蓝色光效、无信息量的城市延时、"AI 赋能未来"式空话。

---

## 2. 产品展示

| 规则 | 落地要求 | 判据 |
|---|---|---|
| 真实产品界面优先 | 优先用真实录屏；`source_type = real_ui_capture` | 素材 manifest 有录屏证据引用 |
| 重要功能使用特写 | 核心功能至少 1 个近景/特写 | shotlist `shot_size` |
| UI 动画要有信息层级 | 一次只强调一个元素（高亮 / 遮罩 / 放大），不得整屏乱动 | 关键帧 + 人工 |
| 展示操作过程而非静态截图 | 至少 2 帧可见状态变化（点击 → 结果） | 帧差检测，`test_signal` 不得冒充 |
| 模拟界面必须标注 | 画面内固定位置标注「模拟演示」，与 `feature_status` 一致 | OCR / 人工逐项签核 |

**真实性标注规则**：`implemented` 的功能可用真实录屏；`in_development` 只能出现进度文字，不得演示"已可用"；`concept_demo` 必须全程标注「概念演示」。任何"帮您按时正确用药"类表述必须是**功能描述**，不得暗示疗效或医学建议。

---

## 3. 情景演绎

| 规则 | 检查 |
|---|---|
| 人物动作自然 | 动作有起止、符合日常逻辑；禁止僵硬定格拼贴 |
| 画面与旁白内容一致 | 语义一致性为 `NEEDS_MANUAL_REVIEW`（程序不可靠），必须人工逐镜头核对 |
| 镜头衔接合理 | 同场景光线方向、人物位置、景别跳切有理由（EDL `transition.reason`） |
| 人物不得突然改变外貌 | 按 `consistency_group` 比对脸/发型/服装/年龄，硬规则违反即 REJECTED |
| 不生成虚假医疗信息 | 禁止诊断结论、疗效对比、服药剂量建议、医生/白大褂权威暗示 |

> 人物一致性只能靠参考帧比对 + 人工复核，不能因为"提示词里写了同一人"就宣称已验证。

## 4. 剪辑节奏（逐项判定：药到适不适合）

| 技法 | 定义 | 药到适用性 | 理由与落地 |
|---|---|---|---|
| **J-cut** | 下一镜头声音先入 | ✅ **强烈推荐** | 用旁白/环境声提前进入，掩盖硬切，适合说明型产品广告；EDL 记 `audio_lead_in` |
| **L-cut** | 上一镜头声音延续到下一画面 | ✅ **推荐** | 让"提醒音"跨到产品界面，强化因果；避免画面声音同时切换的机械感 |
| **Match Cut** | 形状/动作/位置相似转场 | ✅ **推荐（克制）** | 药盒圆形 → 界面圆形按钮；最多用 1 次，避免炫技 |
| **动作衔接** | 在动作中点切镜 | ✅ 推荐 | 手拿起药盒的中段切到特写，比静止切更顺 |
| **视觉节奏** | 镜头时长随信息密度变化 | ✅ 必须 | 前 3 s 短镜头（0.8–1.5 s），功能展示放慢（2–3 s），禁止等分切片 |
| **音乐卡点** | 剪辑点对齐节拍 | ⚠️ **有限使用** | 仅在片头/片尾包装对齐；功能讲解段以**旁白断句**为准，不为卡点牺牲信息完整性 |
| **运动转场** | 甩镜 / 推拉遮挡转场 | ⚠️ 限制 | 最多 1 次；用药场景需要稳重可信，过度运镜会削弱信任 |
| **速度变化 / 升格** | 慢动作 emphasise | ⚠️ 限制 | 仅用于"手停住/犹豫"这类情绪点；不得用于 UI 操作演示（会显得不真实） |
| **声音桥接** | 共用环境音 / 提示音贯穿 | ✅ **强烈推荐** | 用同一个轻柔提醒音串起 3 个场景，形成声音标识 |
| **产品 UI 动效** | 界面元素有序出现 | ✅ 必须 | 层级化、单次单一焦点；禁止整屏粒子/扫描线/无意义科技线条 |

**明确不适合**：快速闪切蒙太奇、强低音 EDM 卡点、炫光粒子开场、镜头抖动滤镜、全程变速、密集拟声词贴纸。理由是产品与"用药安全 / 可信 / 清晰"相关，节奏应稳、信息应可读。

## 5. 画面包装

| 元素 | 规范 | 禁止 |
|---|---|---|
| 文字排版 | 无衬线中文字体；横屏字号 ≥24 px、竖屏 ≥32 px（见 `subtitle_checks.MIN_FONT_PX`）；单行 ≤18 字 | 描边过粗、多行堆叠、艺术字体 |
| 动态字幕 | 淡入/上移 ≤0.25 s；不遮挡主体（IoU 与覆盖率双检） | 弹跳、逐字爆炸、跟随音乐乱抖 |
| 产品信息卡 | 一张卡只讲一个功能；`feature_id` + 状态标注 | 堆参数、放用户评价 |
| 片头 / 片尾 | 片头 ≤1.5 s；片尾含明确 CTA 与"概念演示"汇总标注 | 长 Logo、无 CTA 的空白收尾 |
| UI 动效 | 高亮 → 点击 → 结果，三段式 | 全息扫描、数据流、随机粒子 |
| 图形转场 | 简洁遮罩 / 匹配形状 | 光效爆闪、镜头翻转 |
| 色彩体系 | 以暖白 + 一个品牌主色 + 中性灰为辅；全片统一 | 蓝紫科技渐变、高饱和撞色滥用 |
| 声音标识 | 固定一段 0.5–1 s 轻柔提示音，全片出现 2–3 次 | 音量过大、每切镜都加音效 |

**不要滥用**：光效、粒子、无意义科技线条。它们是"看起来很 AI"的装饰，会稀释产品信息，也不符合可信基调。

## 6. 横屏与竖屏：独立 9:16 布局，不是裁切

| 维度 | 横屏 16:9 | 竖屏 9:16（**独立设计**） |
|---|---|---|
| 主体位置 | 三分法或居中，可左右留白 | 主体上移至画面上 1/3–1/2，为下方字幕留空间 |
| 字幕安全区 | y ∈ [0.70H, 0.94H] | y ∈ [0.72H, 0.94H]；**禁止落在 0.35–0.65H 中部带** |
| 字号下限 | 24 px | **32 px**（竖屏观看距离更近但画面更窄，需更大字） |
| 产品界面 | 可全屏展示 | **重新构图**：只截取关键功能区并放大，不整屏压缩 |
| 重要信息 | 可左右分布 | **纵向重排**：标题 / 功能点 / 状态标注自上而下 |
| UI 安全区 | 四边约 5% | 顶部预留平台 UI、底部预留字幕与操作区 |

落地检查（已在本轮 `subtitle_checks.py` 实现）：`safe_area`、`box_within_canvas`、文字/邻近背景对比度、帧内实测字号、与无字幕参考帧的烧录像素差、主体遮挡多指标。程序不可判定的「文字内容是否与 SRT 一致 / 语义可读性 / 未声明内容遮挡」保留 `NEEDS_MANUAL_REVIEW`，并需**逐项具名人工签核**（见 `subtitle-signoff-fix.md`）。

> 历史缺陷 D004 正是"横屏裁成竖屏 + 字幕落在画面中部 + 字号不足"的反面案例，当前仍 `STILL_FAILING`。竖屏原生重排方案见 `blockers.md`。

## 8. 规范 → 质检的映射

| 规范条目 | 自动可检 | 必须人工 |
|---|---|---|
| 黑屏 / 静音 / 冻结 / 时长 / 分辨率 / 帧率 | ✅ FFmpeg | — |
| 字幕安全区 / 越界 / 实测字号 / 文字对比度 / 烧录证据 | ✅ 本轮 `subtitle_checks.py` | 文字内容 vs SRT、语义可读性 |
| 主体遮挡 | ✅ 已声明框（IoU + 覆盖率） | 未声明内容遮挡 |
| 镜头重复 / 人物一致性 | ✅ 像素/特征比对辅助 | 换脸 / 换衣 / 年龄、语义一致性 |
| 音画同步 / 音乐 ducking | ✅ 时间码比对 | 观感节奏 |
| 产品真实性 / 疗效风险 | ⚠️ 规则匹配（禁用词） | **强制人工逐项签核** |

质量总监对任一 FAIL 拥有一票否决；不得为了通过而把自动 `NEEDS_MANUAL_REVIEW` 改写成 PASS。
