## 5. 阶段 2 之后的自动质检计划（本轮**未执行**）

| 类别 | 检查 | 计划工具 / 方法 |
|---|---|---|
| 视频 | 解码完整性、时长、分辨率、帧率统一、黑屏、意外冻结、异常跳帧、音画不同步 | `ffmpeg -v error -i ... -f null -`、`freezedetect`、`blackdetect`、`ffmpeg -i` 元数据、`ffprobe`（⚠️ 本机 PATH 上**没有** ffprobe，需先定位或用 `ffmpeg -i` 替代） |
| 音频 | 旁白完整、静音段、爆音、底噪、音乐压过旁白、突然音量变化 | `volumedetect`、`silencedetect`、`astats`、旁白/音乐 ≥12 dB 差值、**真人试听** |
| 字幕 | 与旁白一致、错别字、时间轴、安全区、遮挡主体、手机端可读 | SRT↔旁白逐句比对、烧录前后像素差、文字掩膜对比度、安全区坐标、遮挡 IoU + `intersection/subject` |
| 签核 | 自动 PASS ≠ 人工 PASS | 沿用 WB-004 `per_item_signoff_v1`：3 个 MANUAL_ITEMS 逐项具名签核；**不得虚构审核人** |
