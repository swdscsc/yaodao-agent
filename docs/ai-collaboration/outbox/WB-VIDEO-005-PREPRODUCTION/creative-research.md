## 2. 从案例里提炼、并被本片采用的 7 条叙事决策

1. **先给生活，后给产品。** 前 52 秒不出现品牌、不出现设备特写、不解释技术；让观众先认出那个早晨和那通电话。对应案例 2、3、4。
2. **单一价值主张。** 全片只讲一件事：**不用学新东西，只要开口说话**。不把 9 个工具、架构、平台名词塞进 4 分钟。对应案例 1。
3. **把「记不清」拍成物件，不拍成台词。** 药单上被划掉的一行、说明书的小字、贴了又撕的便利贴，比一句「老人记性差」更有说服力，也避免把长辈拍成无能。对应案例 4。
4. **子女不是拯救者，老人不是被拯救者。** C1 让子女「只能再发一句记得吃药」，C5 让老人「自己问得清，也自己答得上」；产品是让主动权回到老人手里的工具。对应案例 4、6。
5. **功能段落用对话体，不用参数表。** 每个功能都是「一句人说的话 → 设备的回答」，画面只留一两行字。这样功能展示与叙事语气不割裂。
6. **主动展示边界，把限制讲成可信度。** C6 用 26 秒讲「它不接什么问题」，是整支片子最不像广告的一段，也是医疗健康题材最重要的一段。对应案例 6 与 `README.md` 的安全边界章节。
7. **结尾不虚构商业渠道。** 行动引导回到一句人能立刻做的事（给爸妈打个电话），而不是编造购买链接、客服电话、"立即体验"按钮。

## 3. 被明确排除的模板化做法

| 排除项 | 原因 |
|---|---|
| 蓝紫渐变 / 数据粒子 / 全息 UI / 光效转场 | 与「家里的一张桌子」的题材冲突；也是本项目反复申明的视觉禁区 |
| 「AI 赋能、重塑、颠覆、开启新时代」等套话 | 无可核实含义，且容易被读成夸大 |
| 旁白念功能清单、屏幕上同时飞出 6 个图标 | 信息过载，老人题材尤其不适合 |
| 演员对着镜头微笑点头 + 竖大拇指 | 廉价证言感，且会被误读为「用户评价」 |
| 前后对比式「使用前混乱 / 使用后井井有条」 | 暗示效果保证，医疗健康题材风险高 |
| 任何疗效、依从性提升百分比、家庭数量、医生背书 | 仓库中无此类数据，一律 `UNVERIFIED` 并排除 |
| 把模拟界面当真实录屏 | 违反任务书红线；本片逐镜标注 `MOCK_UI` |

## 4. 本片原创创意方向（结论）

**片名**：《药到 · 不用学，只要说》
**核心创意**：把「记得吃药」这句话，从子女的反复叮嘱，还给老人自己说出口。
**一句话梗概**：一个总是答不上「今天吃没吃」的早晨，因为一句自然说出口的话，变成了一天里能被自己说清的三顿饭。
**情绪曲线**：静（C0）→ 微微发紧（C1）→ 松开（C2）→ 清楚（C3/C4）→ 暖（C5）→ 郑重（C6）→ 留白（C7）。
**品牌记忆点**：`药到 · 不用学，只要说` + `老人不会用智能手机，但一定会说话`。
**差异化**：不卖「远程监控」，不卖「AI 有多懂你」，卖**它知道自己不该管什么**。

| 标签 | 含义 | 出现位置 |
