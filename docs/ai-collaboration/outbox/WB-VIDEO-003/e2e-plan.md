## 3. 必须区分的六条（防止把参考链路冒充真实链路）

1. **FFmpeg 参考渲染 ≠ 剪映导出**。WB-VIDEO-002 的两个 v2 MP4 是 FFmpeg 产物，本轮严格重质检后已判 **FAIL**（见 `qa-fix-report.md` §1.5），不能作为成片证据。
2. **合成图案 ≠ AI 生成素材**。`testsrc2 / smptebars / color` 只是测试信号，不能登记为 `is_ai_generated=true`。
3. **静态画面 ≠ 动态镜头**。静态彩条 S002 现在会被冻结检测正确判为缺陷，不再被全局豁免掩盖。
4. **文字文件存在 ≠ 字幕正常显示**。必须有 SRT + 画面像素差证据 + 人工签核，才允许标 `FIXED`。
5. **有音频文件 ≠ 配音合格**。占位 sine / BGM 不得标成正式旁白；静音视频不得标成配音完成。
6. **导出成功 ≠ 宣传片质量合格**。导出后仍需 9 项自动质检 + 关键帧 + 具名人工视听复核。
