## 4. 获得授权后的执行顺序

1. 确认采用的路径（P1 / P2 / P3）与许可证记录格式。
2. 生成或取得音频 → 逐个写入 `asset-sources.md` 并附 SHA-256。
3. 用 `volumedetect` / `silencedetect` / `astats` 做自动质检，再人工试听（不得虚构审核人）。
4. 与旁白混合时执行响度与旁白优先检查。
5. 只有以上都完成，才允许进入导出环节。
