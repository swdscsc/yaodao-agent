# workbuddy_reports/ — 执行报告归档

WorkBuddy 每完成一个阶段，把执行报告按以下命名归档到本目录：

```text
WB-VIDEO-007-v1-EXECUTION-REPORT.md
```

每份执行报告必须包含：

1. 任务编号与版本号
2. 当前完成情况（不得把计划写成已完成）
3. 实际修改了哪些文件
4. 新增了哪些交付物
5. 测试和验收结果（自检数据，注明「自检 ≠ 验收」）
6. 尚未解决的问题
7. 对上一轮 ChatGPT 审核意见的逐条回应（v2 起必须有）
8. 下一步建议
