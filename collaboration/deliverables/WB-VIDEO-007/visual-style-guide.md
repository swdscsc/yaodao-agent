## 2. 药到样片执行规范

### 2.1 画布与帧率
- 1080×1920（9:16 竖屏）、30fps、H.264 CRF19 + AAC 192k。
- 造型语言：圆角（chip r=32–37、卡片 r=26、气泡 r=34）；**禁直角硬边**。
- 安全区：字幕底边距 ≥156px；角标距右 ≥60px；顶部信息条距顶 96–120px。

### 2.2 调色（明确拒绝蓝紫科技渐变）
| 角色 | 色值 | 用途 |
|---|---|---|
| 米白底 | `#FAF6EE` | 全片背景基色 |
| 深青主色 | `#0E6E6B` | 品牌字、高亮、进度环、深底段落 |
| 深青暗底 | `#0A4A48` | 落版段背景 |
| 暖橙强调 | `#E9912C` | 下划线、次级高亮、用户气泡、警示 chip |
| 炭黑正文 | `#2D2A26` | 标题与正文 |
| 灰 | `#96918A` | 辅助说明 |

背景运动规范：三个半径 500–640px 的柔光斑（青×2、橙×1，α≈4.5%），按 sin/cos 慢漂（周期 14–22s）——**背景永远在动但不可察觉突兀**。

### 2.3 动效三段式（每个元素必须 入场/停留/退出）
- 入场：ease_out_cubic 位移 40–140px + alpha 0→1，0.4–0.5s；强调元素用 ease_out_back(k=1.2–1.7) 过冲弹入。
- 停留：持续微动（背景漂移、进度环扫动、打字机推进）；停留 ≥1.2s 保证可读。
- 退出：整段 dissolve 0.2–0.45s 或元素随段落淡出；**禁硬切黑**（首尾黑场 0.18s/0.5s 渐变除外）。
- Stagger 节奏：同类元素 0.2–0.25s 递进（三行药卡、三条安全边界、逐字标题 0.07s/字）。
- 打字机：1.1s 打完 12 字，帧率同步逐字推进。

### 2.4 字幕系统
- 位置：y=1660–1764 白胶囊（r=30，α=200）衬底；字号 56px 起、宽度 >920px 自动每档 −4px 降至 34px。
- 分色：正文炭黑、次强调暖橙、强强调深青；与语音逐句对位（t0=语音起点+0.1s）。
- 语音尾部静音实测裁剪（silencedetect −38dB），字幕不早于语音结束 0.3s 消失。

### 2.5 合规标注（每段强制）
| 段 | 标注 | 位置 |
|---|---|---|
| 真机实拍 | 「● 真实设备实拍」白 chip | 左上 (36,48) |
| 模拟服药卡 | 「模拟界面 · 设计示意 · 示意数据」橙 chip | 顶中 |
| 模拟对话 | 「模拟界面 · 对话示例 · 非用药建议」橙 chip | 顶中 |
| 全部段 | 角标（ui/safety 段） | 右下 (W-60-w, 1780) |

### 2.6 声音规范
- 采样 48kHz 立体声；旁白 0.95 增益、0.05s 淡入淡出；音效 0.9。
- Ducking：语音 ±0.4s 外沿 0.25s 斜坡内配乐 −12dB。
- 混音峰值归一 0.89（≈−1dBFS）；首帧 whoosh 卡片头、落版 chime 卡结尾。
- 配乐和弦：F–C–Dm–Am（F 大调五声安全集），piano 音色 env=exp(−2.1t)，pad=hanning^0.65。

## 3. 检验（已在本样片实测）
- 846 帧逐帧渲染 0 异常（先全量扫描再落盘）。
- 字幕宽度自适应后无出界；气泡文字定位修正后无越界。
- 每个 MP4 需通过 ffprobe 流检查 + `-xerror` 全解码（见 quality_report）。
