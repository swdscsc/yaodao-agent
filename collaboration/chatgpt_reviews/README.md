# chatgpt_reviews/ — 审核意见归档

ChatGPT 的审核意见由用户代为提交到本目录，文件命名规范：

```text
WB-VIDEO-007-v1-REVIEW.md     # 任务编号-版本-REVIEW.md
```

## 建议审核意见包含的内容

1. **结论**：通过 / 通过但有修改项 / 返工。
2. **逐项审核结果**：播放性、信息传达、合规标注、视觉风格（对照 CURRENT_STATUS.md 的待审核重点）。
3. **具体问题定位**：尽量给出时间点（秒/帧号）与画面描述，便于 WorkBuddy 直接修改。
4. **下一阶段具体执行指令**：改什么、怎么改、验收标准是什么。

## 归档纪律

- 审核意见一经提交即不可在本目录中修改或删除（保留 git 历史）。
- WorkBuddy 必须在下一版执行报告中逐条回应审核意见（采纳/部分采纳/说明理由），
  不得擅自忽略。
- 审核通过之前，对应版本的成片不得覆盖或重命名。
